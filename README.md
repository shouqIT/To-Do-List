# 📝 To-Do List

A Java-based To-Do List application designed to help users organize, manage, and track their tasks.

## ✨ Features

- ➕ Add new tasks
- 👀 View all tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- ⚠️ Handle invalid menu input
- 🔄 Interactive menu using a loop

## 🛠️ Technologies Used

- Java
- ArrayList
- Scanner
- Exception Handling
- Switch Statement
- Loops
- Object-Oriented Programming

## 📋 How It Works

When the program starts, a menu is displayed with the following options:

1. Add Task
2. View Tasks
3. Mark Task as Done
4. Delete Task
0. Exit Program

The user selects an option by entering its corresponding number.
